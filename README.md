# duyubo.github.io

Personal academic homepage of Yubo Du, built with [al-folio](https://github.com/alshedivat/al-folio).

- Edit the bio in `_pages/about.md`, the research page in `_pages/research.md`, and news in `_news/`.
- Publications come from `_bibliography/papers.bib`.
- Replace `assets/pdf/Yubo_Du_CV.pdf` and `assets/pdf/Yubo_Du_Research_Statement.pdf` to update the CV and statement.
- Every push to `main` builds the site with GitHub Actions and deploys it to the `gh-pages` branch.
