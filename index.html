Research

Deterministic defenses are reliable but expensive, and AI is efficient but unreliable. The two are complementary: AI decides where to focus, and deterministic methods decide what is true.

Efficient Deterministic Defense

My published work makes deterministic defenses fast enough for real-world software:

  • FPN: Fast Pointer Nullification for Use-After-Free Prevention (NDSS 2026). A runtime defense that stops use-after-free attacks in deployed C/C++ software. FPN tracks pointers in groups by their locality while keeping protection exact, which reduces memory overhead from about 173% to about 8%. [Paper] [Code]
  • RTT-UAF: Reuse Time Tracking for Use-After-Free Detection (ICS 2024). A sanitizer that finds use-after-free bugs during testing. RTT stores a small reuse count in the unused bits of each pointer, so no metadata needs to be propagated, which cuts runtime overhead by up to 7×. [Paper]

Combining Deterministic Checking with AI

My ongoing work goes beyond pure deterministic defense and combines deterministic checking with AI:

  • Diagnostic vulnerability detection. A sanitizer that reports not only where an out-of-bounds error occurs, but also which buffer is involved and where the pointer first goes out of bounds, so that developers and AI repair tools can find the root cause directly.
  • Verifying the reasoning of AI (at Carnegie Mellon University). A sanitizer-style checker that compares each step of a large language model’s vulnerability analysis with the real behavior of the program, to find where AI reasoning goes wrong and which code patterns mislead it.

Selected Publications

  1. Fast Pointer Nullification for Use-After-Free Prevention
    Yubo Du, Youtao Zhang, and Jun Yang
    In Proceedings of the Network and Distributed System Security Symposium (NDSS), 2026
    Abs Bib PDF Code

    FPN is a runtime defense that prevents use-after-free attacks in deployed C/C++ software by invalidating dangling pointers when a buffer is freed. It uses the locality of pointers to track them in groups, while a fine-grained label keeps protection exact. FPN reduces memory overhead from about 173% to about 8% and runtime overhead from about 56% to about 18% compared with the latest precise pointer-tracking defense.

  2. RTT-UAF: Reuse Time Tracking for Use-After-Free Detection
    Yubo Du, Yanan Guo, Youtao Zhang, and Jun Yang
    In Proceedings of the 38th ACM International Conference on Supercomputing (ICS), 2024
    Abs DOI Bib HTML

    RTT is a key-and-lock sanitizer that uses the number of times an address has been reused as the identifier of a buffer. The identifier fits in the unused upper bits of a pointer, so no metadata needs to be propagated. RTT reduces runtime overhead by up to 7x and memory overhead from more than 100% to under 8%, with the same detection rate on real-world use-after-free vulnerabilities.
